# AngkasaDev — Design System v1

## Direction
Creative Engineering Studio. Blend expressive visual storytelling with enterprise-level clarity. Avoid generic AI/tech gradients, ornamental blobs without purpose, repetitive feature cards, and unverified social proof.

## Tokens
- Canvas `#F7F6F2`
- Ink `#171717`
- Primary action indigo `#4569F5`
- Signature orange `#FF713B`
- Accent lime `#D8F59C`
- Body muted `#66645F`
- Border `#D9D8D2`

Manrope headings, DM Sans body; 18–24px cards, pill CTAs, larger rounding on dark section plates. Accent orange not used for primary buttons. Warm neutral breathing room with strong editorial layout.

## UX
- Touch-friendly buttons, skip nothing essential on mobile.
- Respect `prefers-reduced-motion`.
- Correctly-labelled form fields, visible keyboard focus, semantic headings.
- Portfolio must explicitly distinguish conceptual illustrations from actual published client case studies.

## Phases
1. Validate provisional monogram and actual corporate branding assets.
2. Replace concept projects with authorized screenshots/case studies.
3. Replace editorial placeholder with genuine bilingual articles.
4. Verify form + security + DNS before production.
